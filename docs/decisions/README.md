# Decision log

Decision records capture constraints that should remain understandable and authoritative after the
implementation changes. Use `YYYY-MM-DD-title.md`, the template in `.agents/templates/`, and one of
these statuses: `proposed`, `accepted`, `rejected`, `deprecated`, or `superseded`.

Accepted decisions remain binding until a later record names them in `supersedes`. Never rewrite
history to make an old decision look current.
