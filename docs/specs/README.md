# Historical specifications

Files in this directory are dated snapshots of requirements or design expectations at a specific
time. They are intentionally not standing instructions.

- Name files `YYYY-MM-DD-title.md`.
- Keep the original snapshot intact.
- Add frontmatter with `date`, `title`, `status: historical-snapshot`, and `superseded_by`.
- Before using a specification as an implementation requirement, ask the user whether it remains
  applicable.
- Record lasting decisions in `docs/decisions/` instead.
