# DesktopAutomation documentation

Documentation is separated by authority and lifetime:

- `architecture/` describes the current system and its public technical contracts.
- `decisions/` records durable design decisions and their consequences.
- `specs/` contains dated historical requirement snapshots. Confirm them with the user before use.
- `guides/` contains maintained operational and contributor guides.

Agent-specific instructions and repeatable workflows live under `.agents/`.
